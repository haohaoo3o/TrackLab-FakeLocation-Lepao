# Android 13+ 与 MIUI 权限指南

TrackLab 使用地图、前台回放、可选悬浮控制和 Android 官方 Mock Location。不同系统版本与厂商界面名称可能不同；以下路径用于排查，不替代设备厂商文档。

## 权限与系统能力

| 系统版本 | 权限或设置 | 用途与未授权行为 |
|---|---|---|
| Android 8.0+ | 精确位置、近似位置 | 地图定位和位置测试的前置条件；缺失时停止相关流程并显示引导 |
| Android 8.0+ | 开发者选项中的“选择模拟位置信息应用” | 选择 TrackLab 后才可通过官方测试位置提供者输出模拟位置 |
| Android 8.0+ | 前台服务 | 在用户可感知的情况下持续回放 |
| Android 13+ | 通知 | 显示前台回放通知和控制操作；拒绝后通知可见性受限 |
| Android 14+ | 位置类型前台服务 | 启动 location 类型前台服务所需；同时需要位置权限 |
| 所有支持版本 | 显示在其他应用上层 | 可选悬浮控制；未授权时不显示，主界面控制仍可用 |
| 所有支持版本 | 网络访问 | 加载高德地图、定位和搜索服务 |

## 启用 Mock Location

1. 打开“设置 → 关于手机”；
2. 连续点击系统提示的“版本号”入口，启用开发者选项；
3. 打开“设置 → 系统/更多设置 → 开发者选项”；
4. 找到“选择模拟位置信息应用”或同名入口；
5. 选择 **TrackLab**；
6. 返回 TrackLab，重新开始回放。

同一时刻 Android 通常只允许选择一个模拟位置应用。切换应用后，应停止并重新开始当前回放。

TrackLab 使用 Android 官方测试位置提供者，不隐藏 mock 标记。未选择 TrackLab 时，系统可能拒绝注册测试提供者，应用会显示操作引导；应用内地图预览不依赖该输出是否成功。

## Android 13 通知权限

Android 13 / API 33 起，通知需要运行时授权。TrackLab 的前台服务仍必须立即创建前台通知，但用户拒绝通知权限后，通知抽屉中的可见性和提醒方式由系统决定。

若看不到回放通知：

1. 打开“设置 → 应用 → TrackLab → 通知”；
2. 允许通知并检查对应通知渠道；
3. 在 MIUI 等系统中同时检查厂商提供的通知、锁屏通知和横幅开关；
4. 返回应用重新开始回放。

应用界面的测试状态标识和主界面控制不依赖通知权限。

## Android 14 位置前台服务

Android 14 / API 34 起，location 类型前台服务需要相应前台服务权限，并要求启动时已具备适用的位置权限。若用户撤回精确位置或只保留不满足功能要求的授权，TrackLab 会在开始前显示权限引导。

Android 12 及以上限制应用从后台启动前台服务。若系统拒绝从悬浮控件等后台上下文发起，TrackLab 会返回主界面，请用户在前台明确开始。项目不绕过该系统限制。

## 悬浮控件

“显示在其他应用上层”是特殊权限，没有普通运行时授权弹窗。可按以下路径手动开启：

```text
设置 → 应用 → 特殊应用权限 → 显示在其他应用上层 → TrackLab
```

未授权时，悬浮控件不会显示；仍可通过 TrackLab 主界面以及可见通知控制回放。

## MIUI 排查

MIUI 不同版本的菜单名称和策略可能变化，常见检查项包括：

- “设置 → 应用设置/应用管理 → TrackLab → 权限管理”中的位置和通知权限；
- “其他权限/特殊权限”中的显示悬浮窗或后台弹出界面；
- “通知管理”中的锁屏通知、悬浮通知和声音；
- “省电策略”中的后台限制；
- “自启动管理”中的自启动开关；
- “更多设置 → 开发者选项”中的模拟位置应用选择。

这些厂商设置可能影响通知、悬浮窗和长时间后台运行。TrackLab 使用 `START_NOT_STICKY`；进程被系统终止后不会自动恢复运行，下一次启动只恢复为暂停状态，以避免未经用户确认继续输出位置。

## 撤回权限与删除数据

- 在应用权限页面撤回位置或通知权限；
- 在特殊权限页面撤回悬浮窗权限；
- 在开发者选项中取消 TrackLab 的模拟位置应用选择；
- 停止回放以移除测试位置提供者；
- 在“存储”页面清除应用数据，或卸载应用，以删除应用私有状态；
- GPX/GeoJSON 写入 TrackLab 的应用专属 external files `exports` 目录（不可用时回退到内部 `filesDir/exports`），不经过系统文件选择器；卸载可能删除这些文件，如需保留必须先复制到应用专属目录之外。

完整数据处理说明见 [隐私政策](../PRIVACY.md)。
